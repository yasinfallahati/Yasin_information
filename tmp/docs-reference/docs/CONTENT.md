**Long:**

FA: یک پلتفرم جامع DevOps که هوش مصنوعی را با مدیریت زیرسافت ترکیب می‌کند. NexusOps مانیتورینگ بلادرنگ، استقرارهای خودکار، تحلیل لاگ و هشدارهای هوشمند برای زیرسافت مدرن ارائه می‌دهد.

**Short:**

EN: Personal developer portfolio website representing Saman's technical journey, projects and skills.

**Short:**

EN: A read-only Telegram bot for monitoring Linux server health, including CPU, RAM, disk, uptime, and Docker containers.

FA: یک ربات Telegram فقط خواندنی برای مانیتورینگ سلامت سرور Linux، شامل CPU، RAM، دیسک، آپتایم و کانتینرهای Docker.
