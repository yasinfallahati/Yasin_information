# Content Guide / راهنمای محتوا / Inhaltsleitfaden

## English

Maintain all visitor-facing strings in the `copy` object in `src/App.jsx`. When adding a language, include `dir`, all labels, and contact copy. Keep technology names in their common form (for example, `FastAPI`, `GitHub`, `REST API`) across languages.

## فارسی

تمام متن‌های قابل‌مشاهده در سایت در شیء `copy` در فایل `src/App.jsx` نگهداری می‌شوند. هنگام افزودن زبان جدید، `dir`، همهٔ برچسب‌ها و متن بخش تماس را وارد کنید. نام فناوری‌ها مانند `FastAPI` و `GitHub` در همهٔ زبان‌ها به شکل رایج نوشته می‌شوند.

## Deutsch

Alle sichtbaren Texte liegen im Objekt `copy` in `src/App.jsx`. Bei einer neuen Sprache müssen `dir`, alle Labels und der Kontakttext ergänzt werden. Technologiemarken bleiben in ihrer üblichen Schreibweise.

## Project content / محتوای پروژه / Projektinhalte

Pinned repositories are synchronized to `public/pinned-projects.json`. Give every pinned repository a concise description, a primary language, and meaningful topics in GitHub for better cards.
