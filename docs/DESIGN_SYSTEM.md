# Design System / سیستم طراحی / Designsystem

## Tokens

| Token | Dark | Light | Use |
|---|---|---|---|
| `--bg` | `#070b15` | `#f5f8ff` | Page background |
| `--panel` | translucent dark | translucent white | Cards and controls |
| `--text` | `#f8fafc` | `#14213a` | Primary text |
| `--muted` | `#9dacbf` | `#53647d` | Supporting text |
| `--blue` | `#3378ff` | `#1f65e8` | Main action |
| `--purple` | `#8955f7` | `#7543df` | Accent gradient |

## English

The visual language is dark-first technical glass: a soft grid, restrained blue/purple gradients, rounded panels, and high-contrast text. Light mode must change every surface, not merely invert body text. The desktop sidebar becomes a compact top dock and then a bottom dock on small screens.

## فارسی

زبان بصری سایت تیره و فنی است: grid ملایم، طیف آبی/بنفش کنترل‌شده، کارت‌های گرد و متن پرکنتراست. در حالت روشن همهٔ سطح‌ها باید تغییر کنند، نه فقط رنگ متن. سایدبار دسکتاپ در نمایشگرهای کوچک به dock بالا و سپس dock پایین تبدیل می‌شود.

## Deutsch

Die visuelle Sprache ist technisch und Dark-first: dezentes Raster, kontrollierte Blau-/Violett-Verläufe, abgerundete Flächen und hoher Kontrast. Im Light Mode müssen alle Flächen angepasst werden. Die Desktop-Sidebar wird auf kleinen Geräten zu einem Dock.

## Typography / تایپوگرافی / Typografie

- Latin: `Inter`; monospace labels: `DM Mono`.
- Persian: `Salsiza` when installed, otherwise `Vazirmatn`.
- RTL headings use a smaller scale and more line height because Persian glyphs occupy more visual space.
