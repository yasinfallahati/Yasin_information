| Component | English | فارسی | Deutsch |
|---|---|---|---|

## Accessibility / دسترسی‌پذیری / Barrierefreiheit

- Interactive controls are native links or buttons.
- External links use `rel="noreferrer"`.
- Icon-only controls require an `aria-label` or visible tooltip.
- Do not communicate state with color alone.
- Keep target areas comfortably tappable on mobile.
