## Quick start / شروع سریع / Schnellstart

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
```

For production, push to `main`. GitHub Actions builds and deploys the site to GitHub Pages.

برای انتشار، تغییرات را به شاخهٔ `main` پوش کنید؛ GitHub Actions سایت را build و روی GitHub Pages منتشر می‌کند.

Für die Veröffentlichung auf `main` pushen; GitHub Actions baut und veröffentlicht die Website auf GitHub Pages.
