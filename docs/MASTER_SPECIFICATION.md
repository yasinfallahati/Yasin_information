## English

This site is a multilingual personal portfolio for an AI, automation, backend, and web developer. It turns GitHub work into an accessible professional profile. The portfolio must remain fast, readable, mobile-friendly, and truthful: projects are evidence; skills are explicitly maintained by the owner.

### Product principles

1. Show evidence, not inflated claims.
2. Keep navigation simple and useful.
3. Persian is a first-class RTL experience, not a translated afterthought.
4. Respect reduced motion, keyboard navigation, and readable contrast.
5. Keep deployment automatic and reversible through Git history.

3. فارسی یک تجربهٔ RTL کامل است، نه ترجمهٔ فرعی.
