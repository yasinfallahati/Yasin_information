# Product Requirements Document / سند نیازمندی محصول / Produktanforderungen

## English

### Goal

Help recruiters, collaborators, and clients understand Yasin's capabilities and contact him in under two minutes.

### Primary users

- Recruiters looking for an AI, backend, or automation developer.
- Teams evaluating practical web and API skills.
- Technical collaborators reviewing GitHub projects.

### Required experience

| Area | Requirement |
|---|---|
| Language | Persian, English, German switcher with persisted choice |
| Theme | Light/dark switcher with persisted choice |
| Projects | Pinned GitHub repositories rendered from `public/pinned-projects.json` |
| Skills | Owner-maintained categorized skills with visual icons |
| Contact | Email, GitHub and Telegram links |
| Responsive | Usable from 320px to large desktop screens |

### Out of scope

No user accounts, comments, analytics tracking, backend database, or project editing UI.

## فارسی

### هدف

بازدیدکننده در کمتر از دو دقیقه توانایی‌ها، پروژه‌ها و راه ارتباطی با یاسین را پیدا کند.

### کاربران اصلی

- استخدام‌کنندهٔ دنبال توسعه‌دهندهٔ AI، بک‌اند یا اتوماسیون.
- تیم‌هایی که توانایی API و وب را ارزیابی می‌کنند.
- همکارانی که پروژه‌های GitHub را بررسی می‌کنند.

### نیازمندی‌ها

تغییر زبان و تم باید ذخیره شود؛ پروژه‌های Pin‌شده نمایش داده شوند؛ مهارت‌ها دسته‌بندی شوند؛ لینک ایمیل، GitHub و Telegram در دسترس باشد؛ و سایت از موبایل تا دسکتاپ قابل استفاده بماند.

## Deutsch

### Ziel

Recruiter, Teams und Kollaboratoren sollen Fähigkeiten, Projekte und Kontaktmöglichkeit in weniger als zwei Minuten verstehen.

### Anforderungen

Sprach- und Theme-Auswahl werden gespeichert; angeheftete GitHub-Projekte werden angezeigt; Skills sind kategorisiert; E-Mail, GitHub und Telegram sind erreichbar; das Layout bleibt responsiv.
